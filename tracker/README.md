# 시세트래킹 (개인용)

내가 정한 유닛(단지)의 네이버페이부동산 **매매 호가**를 매일 읽어서
59㎡/84㎡ 최저가를 기록하고, 전날과 비교해 변동이 있으면 알려줍니다.

- 브라우저가 단지 매물 화면을 열고 끝까지 스크롤하며 **화면에 보이는 글자**를 읽는 방식입니다. 피클과 같은 방식이고, 네이버 API는 쓰지 않습니다.
- **반드시 내 PC에서 실행해야 합니다.** 클라우드 서버에서는 네이버가 응답하지 않습니다.
- 개인 참고용입니다. 수집한 호가를 공개 사이트에 그대로 올리지 마세요. `data/`, `reports/` 폴더는 저장소에 올라가지 않습니다.

## 처음 한 번 설치 (Windows)

1. [Node.js](https://nodejs.org) LTS 버전을 설치합니다.
2. 명령 프롬프트를 열고 이 폴더로 이동한 뒤 아래 두 줄을 실행합니다.
   ```
   npm install
   npm run setup
   ```

## 실행

```
run.bat                     ← 전체 유닛 수집 + 리포트
run.bat --show              ← 브라우저 창을 띄워서 진행 과정 보기 (처음엔 이걸로 확인 추천)
run.bat --report-only       ← 수집 없이 최근 자료로 리포트만 다시 만들기
run.bat --group "서울 13개 단지"
```

- 13개 단지 기준으로 약 5~15분 걸립니다(단지마다 천천히 스크롤).
- 결과물은 아래 두 곳에 저장됩니다.
  - `reports/날짜.md`: 리포트 (주요 변동, 단지별 최저가, 59/84 격차)
  - `data/날짜.json`: 그날 읽은 매물 전체 (전일 비교와 추이에 사용)
- 리포트에 `⚠️60/482건만 읽음`이 보이면 스크롤이 끝까지 안 된 것입니다. `--show`로 화면을 확인해 주세요.

## 유닛 관리: `units.json`

```json
"groups": {
  "서울 13개 단지": [
    { "id": 22627, "name": "잠실엘스", "gu": "송파", "areas": { "59": [58, 61], "84": [83, 86] } }
  ],
  "갈아타기 후보": [ ... ]
}
```

| 항목 | 내용 |
|---|---|
| 그룹 | 원하는 대로 목록을 나눌 수 있습니다 |
| `id` | 네이버페이부동산 단지 주소 `fin.land.naver.com/complexes/번호`의 번호 |
| `areas` | `"표시이름": [전용 최소, 최대]`. 잠실주공5단지처럼 평형이 다른 단지는 76/82처럼 바꿔 넣습니다 |

## 변동 알림 (메일)

`tracker/.env` 파일을 만들고 아래처럼 적으면, 변동이 있는 날 메일이 옵니다.

```
GMAIL_USER=내지메일@gmail.com
GMAIL_APP_PASSWORD=앱비밀번호16자리
ALERT_TO=받을주소@gmail.com
```

앱 비밀번호는 Google 계정 → 보안 → 2단계 인증 → 앱 비밀번호에서 만듭니다. 일반 비밀번호는 쓸 수 없습니다.

## 매일 자동 실행 (Windows 작업 스케줄러)

1. 작업 스케줄러에서 **기본 작업 만들기**를 누릅니다.
2. 트리거는 **매일**, 시간은 원하는 시각(예: 새벽 4:10)으로 정합니다.
3. 동작은 **프로그램 시작**, 프로그램은 이 폴더의 `run.bat`을 선택합니다.
4. 설정에서 "예약된 시간을 놓친 경우 가능한 빨리 작업 시작"을 켭니다.

PC가 켜져 있어야 실행됩니다(절전 모드에서 깨우기를 켜도 됩니다).
